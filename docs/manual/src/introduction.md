# Welcome to Ettin Edit

<p><img class="hero" src="images/ettin.svg" width="200" alt="Edda and Ottar, the two-headed Ettin Edit mascot"></p>

Ettin Edit is a fast, friendly text editor for Linux and Windows. It is
inspired by Notepad++, shares none of its code, and builds in the tools people
usually add to Notepad++ with plugins: JSON and XML tools, a compare view,
SQL over CSV files, and more.

This manual explains how to use every part of the editor and how to make it
your own. You can read it in two places:

- in Ettin Edit, from **Help > User Manual** (<kbd>Shift+F1</kbd>), which works
  without an internet connection, and
- on the web at <https://tharkis.github.io/Ettin-Edit/>.

Both show the same text, written for the version of Ettin Edit you have.

## Meet the heads

In Norse myth an *ettin* is a giant, and the famous ones had more than one
head. Ours has two. **Edda** keeps your tabs in order and has never once lost
an unsaved file. **Ottar** compares everything with everything else and keeps
asking for one more plugin. You'll see their opinions in the odd tip box.

## Finding your way around this manual

- The contents are on the left. In the app, the box at the top searches every
  page; on the web, press <kbd>S</kbd> or click the magnifying glass.
- Menu commands are written like **File > Open…**: open the **File** menu,
  then choose **Open…**.
- Keyboard shortcuts look like <kbd>Ctrl+Shift+F</kbd>. These are the
  defaults; if you change them in the [Shortcut Mapper](shortcuts.md), the
  menus show your own.
- Every command is also in the **command palette**: press <kbd>F1</kbd> and
  type a few letters of its name.
