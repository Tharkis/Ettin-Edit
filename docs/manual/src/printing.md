# Printing and exporting

## Printing

**File > Print…** (<kbd>Ctrl+P</kbd>) opens the document in your web
browser's print preview, where you choose the printer, page size, margins
and which pages to print. Using the browser means printing works the same on
every system and you get a proper preview.

The printout keeps the syntax colours, darkened so they read well on white
paper. If you use a dark theme, the colours of Ettin Light are used instead,
so you don't print a page of black ink. Line numbers are printed in the
margin.

Both can be turned off in [Preferences](preferences.md), under **Files and
Startup > Printing**: **Print line numbers** and **Print syntax colours**.

To save a PDF, choose **Save as PDF** (or **Microsoft Print to PDF**) as the
printer in the browser's print dialog.

## Export as HTML

**File > Export as HTML…** saves the document as a web page with the current
theme's colours and font, ready to put on a website or attach to an email.
Line numbers are included when they're turned on in the **View** menu.
